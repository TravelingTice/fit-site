Move again.

Jakarta, then dad life. Goal: more energy, thicker upper body, lose the belly band, move without it feeling like effort.

1Monthly check-in — the 1st

  • 3 photos: front, side, back — same spot, same light
  • Waist at the navel (the belly number)
  • Weight + one lift number (best incline DB press ×8)
  • Send it to one person who'll notice if it doesn't come

This is what worked in Taiwan. Everything else exists to make this message look good.

2Gym 3× a week, late afternoon

5 min bike warm-up → lifts → 15 min incline walk + podcast. Headphones on before leaving home.

A · Upper

  • Incline DB press3×8–10
  • Lat pulldown3×10
  • Cable row3×10
  • Lateral raise3×15
  • Curl + pushdown2×12

B · Lower + core

  • Leg press / goblet squat3×10
  • Romanian deadlift3×10
  • Walking lunges2×10/leg
  • Hanging knee raise3×12
  • Plank3×40s

C · Upper

  • Pull-ups (assisted)3×max
  • Seated DB shoulder press3×10
  • Chest-supported row3×10
  • Dips / push-ups3×max
  • Hammer + overhead triceps2×12

Add a rep each week; top of range → more weight. Log every set in Hevy/Strong.

3New block every 6 weeks

Never run the same program twice in a row. Seven years of one routine is what killed it last time. Next ideas: padel, climbing gym, swimming, push/pull/legs, a strength block.

4Baby-proof floor

  • Minimum: 10 min at home daily — push-ups, squats, hip & upper-back stretches
  • Survival gym: 2× 30 min, first 3 exercises only

Never miss twice in a row.

5The belly is food

  • Protein ~1.6 g per kg bodyweight
  • Watch es teh manis, kopi susu gula aren, gorengan
  • Keep rice, just smaller
  • Expect ~1–2 cm off the waist per month
